# 1.0 Ways of Working

## Chapter Goals

 1. Become introduced to agile development practices and how teams plan and track work.
 2. Experience both solo development and pair programming.
 3. Understand how testing, code review, and automated quality checks build confidence in every change.
 4. Familiarize yourself with tools needed to successfully complete Liatrio's Engineering Bootcamp.
 5. Be able to describe DevOps in your own words.
 6. Know Liatrio's view on DevOps.
 7. Explore some other resources for learning about DevOps.
