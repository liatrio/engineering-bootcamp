# Pair Programming

Pair programming is two developers working together on the same code at the same time. It keeps both people fully aware of what's happening in the code, catches mistakes as they're made, and spreads knowledge across the team, so no one person is the only one who understands a piece of the system.

## How It Works

- **The driver** types, focusing on the immediate task.
- **The navigator** reviews each line as it's written, thinks ahead, and spots problems.
- **Swap roles regularly**, for example at natural breakpoints such as a passing test, so both people stay engaged.
- **Rotate pairs** every few days, so knowledge spreads across the whole team.

Martin Fowler's [On Pair Programming](https://martinfowler.com/articles/on-pair-programming.html) covers more styles, benefits, and common challenges.

## Remote Pair Programming

When you're not at the same desk, a shared editor lets both people edit and navigate the code at once.

**VS Code Live Share.** In [VS Code](https://code.visualstudio.com/download), open the Extensions tab, search for "Live Share", and install the "Live Share" and "Live Share Extension Pack" extensions. Then select the Live Share icon on the activity bar, and use "Session Details" to share or join a workspace. Live Share also shares terminals, debugging sessions, and local servers, and the extension pack adds text and audio chat.

![How to access Live Share extension](img/live_share_extension.svg ':size=1000x1000 :class=img-center')

**JetBrains Code With Me.** In JetBrains IDEs such as [IntelliJ IDEA](https://www.jetbrains.com/idea/), the Code With Me plugin lets participants join your locally running project to edit code, share a server, and debug together.

## Deliverable

Try out pair programming with someone to program an application that prints "Hello World" using a language of your choice. Swap driver and navigator at least once.
